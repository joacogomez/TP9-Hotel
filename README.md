# Hotel Cerro Alto – Trabajo Práctico N°9 (Lenguaje IV)

Página de reservas de un hotel hecha con React + Vite.

## Componentes (carpeta `src`)
- `Header.jsx`
- `Inicio.jsx`
- `AcercaDeNosotros.jsx`
- `Reservas.jsx` (4 habitaciones + calendario de rango de fechas + `alert` de confirmación)

## Correr en local
```bash
npm install
npm run dev
```

## Deploy en Vercel
1. Subir el proyecto a un repositorio de GitHub.
2. En vercel.com → *Add New Project* → importar el repositorio.
3. Vercel detecta Vite solo (build: `npm run build`, output: `dist`). Click en *Deploy*.
